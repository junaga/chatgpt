# ChatGPT for Linux

Unofficial x86-64 Linux port of the ChatGPT Codex desktop app.

## Install

```bash
curl -fLO https://github.com/junaga/chatgpt/releases/latest/download/chatgpt.deb
sudo apt install ./chatgpt.deb
```

Other release formats include RPM, Arch Linux, AppImage, Snap, Flatpak,
tarball, NixOS, and Gentoo.

## Features

Supports native Wayland, Codex Voice, Browser Use, Computer Use, remote
control, notifications, dictation, and Picture-in-Picture.

This is an independent compatibility project, not an OpenAI product. See the
[port report](REPORT.md) for implementation details and known limitations.
